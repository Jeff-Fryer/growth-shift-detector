# Growth Shift Detector

A free tool that turns a company name and website into a research prompt for ChatGPT, Claude, or Gemini. The prompt looks outside the company for changes that could be affecting growth.

Free. No email, card, monthly plan, or trial.

## What's here

- `index.html` is the whole tool. One file, no dependencies, no tracking. It runs entirely in your browser.
- `og-image.png` is the social preview image (1200 x 627).

## Use it

Open `index.html` in a browser, or use the hosted version at https://www.jefffryer.com/growth-shift-detector
